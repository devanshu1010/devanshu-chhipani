# Role: Code & Quality Reviewer

## Responsibilities
- Review all changes before commit or task completion.
- Verify TypeScript types, bundle impact, lint rules, and runtime regressions.
- Enforce the caveman response standard and check for dead code or unnecessary complexity.

## Skills Used
- `superpowers:verification-before-completion`
- `superpowers:requesting-code-review`
- `superpowers:receiving-code-review`
- `caveman:caveman-review`
- `caveman:verify-and-stop`

## Verification Command
```bash
npm run build && npm run lint
```
