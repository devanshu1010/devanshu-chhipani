# Project Context

## Project Overview
- **Name**: Devanshu Chhipani Portfolio
- **Type**: Interactive Web Portfolio & Blog
- **Author**: Devanshu Chhipani
- **Architecture**: Single Page Application (SPA) with React Router, Vite, Tailwind CSS, shadcn/ui, and Lenis smooth scrolling.

## Key Goals
1. Deliver a premium, responsive, high-performance portfolio showcasing projects, experience, tech stack, and writing.
2. Provide smooth micro-interactions, scroll triggers, and fluid UI choreography.
3. Maintain accessible, performant, clean modular TypeScript architecture.

## Primary Routes
- `/`: Main portfolio page (`Index.tsx`) with Hero, TechStack, Experience, Blog, Contact, CursorGlow, FloatingEmail, FloatingSocial.
- `/blog/:id`: Individual blog article view (`BlogPost.tsx`).
- `*`: 404 handler (`NotFound.tsx`).
