# Project Scope Boundaries

## In-Scope
1. Personal developer portfolio website for Devanshu Chhipani.
2. Experience showcases, technical skill visualizers, blog articles, and contact methods.
3. Fluid micro-interactions, responsive styling, and accessible UI components.
4. Seamless agent-agnostic configuration for collaborative AI pair-programming.

## Out-of-Scope
1. Heavy backend servers, databases, or SSR hosting architectures (site is a Vite SPA).
2. Large unoptimized assets or uncompressed media exceeding web performance budgets.
3. Adding heavy unneeded npm dependencies without explicit purpose.
4. Breaking mobile responsiveness or accessibility standards (WCAG AA).
