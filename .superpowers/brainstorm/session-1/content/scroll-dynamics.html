Dual Scroll Physics & Animation Engines

How GSAP & Lenis power two entirely different "feels" for the same portfolio

SE Mode (Systems) SNAP / TACTILE

The Technical Blueprint

Feels like reading a polished RFC, system manual, or boot sequence. Rigid, predictable, and exact.

SCROLL PHYSICS: STRICT & DAMPENED
Lenis is tuned for high friction and low inertia. The page stops exactly when the user stops scrolling. No floaty drift.
ENTRY ANIMATIONS: CLIP & SNAP
Cards and text reveal via strict geometric masks (`clip-path: inset(100% 0 0 0)`). Easing is sharp (`power3.out`). Typography types out like a telemetry log.
SCROLL EFFECTS: PROGRESS & TRACING
As you scroll down, a hairline circuit trace draws down the left margin, acting as a progress bar connecting the architecture layers logically.
AI Mode (Research) FLUID / PARALLAX

The Latent Space

Feels immersive, boundless, and cinematic. Like navigating through a multi-dimensional embedding space.

SCROLL PHYSICS: HIGH INERTIA (BUTTERY)
Lenis is tuned for smooth, gliding momentum. Scrolling feels like drifting through an environment rather than reading a page.
ENTRY ANIMATIONS: BLUR & EMERGE
Elements emerge from a deep gaussian blur (`filter: blur(20px)`), scaling up slightly as if crystallizing out of the latent space. Extremely soft, long easing.
SCROLL EFFECTS: VELOCITY-DRIVEN 3D
Background 3D particles and vector nodes warp and stretch based on scroll velocity. Heavy use of parallax layering to create immense Z-axis depth.

How we engineer this technically:

We don't need two completely different React applications. Instead, we use a global context (`PersonaContext`) to feed different configuration objects to our animation providers.

  • Lenis Re-initialization: When the persona toggles, we dynamically destroy and re-initialize the Lenis scroll instance with different physics parameters (e.g., `lerp: 0.1` for AI vs `lerp: 0.5` for SE).
  • GSAP ScrollTrigger Contexts: We wrap our section animations in `useGSAP` hooks that explicitly depend on the `persona` state. If `persona === 'se'`, we register the clip-path animations. If `persona === 'ai'`, we kill those and register the blur/scale animations.
  • CSS Variables: Root CSS variables (`--bg-color`, `--border-opacity`, `--font-family`) swap instantaneously, ensuring the structural DOM remains identical while the "paint" changes.
